# Feature: Advanced CSV Editing

## Goal
Nâng cấp `CsvEditorModal` để hỗ trợ các tính năng chỉnh sửa dữ liệu CSV nâng cao, giống với các ứng dụng spreadsheet.

## Tasks
- [x] **Task 1**: Thêm/Xóa/Sửa tên cột.
  - [x] Nút thêm cột mới.
  - [x] Nút xóa cột (có thể đặt trên tiêu đề cột).
  - [x] Cho phép click đúp vào tiêu đề cột để sửa tên cột.
- [x] **Task 2**: Thêm dòng mới.
  - [x] Nút thêm dòng mới ở cuối cùng.
- [x] **Task 3**: Chọn vùng (Selection).
  - [x] Cho phép click và kéo chuột (drag) để chọn nhiều ô.
- [x] **Task 4**: Hỗ trợ Copy, Paste và Xóa (Clear).
  - [x] Phím tắt `Ctrl + C` để copy vùng đã chọn.
  - [x] Phím tắt `Ctrl + V` để dán dữ liệu từ clipboard vào vùng đã chọn.
  - [x] Phím tắt `Delete` hoặc `Backspace` để xóa giá trị của các ô đã chọn.
